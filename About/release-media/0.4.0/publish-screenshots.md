# 0.4.0 "Map & Placement" — publish screenshots

Screenshot set to post with the 0.4.0 Workshop update / release, captured during the
placement-dialog + mod-menu polish. All PNGs are present in this folder, ready to attach.

## The set (in suggested post order)

1. **`01-placement-basic.png`** — Geographic Placement Settings, **Basic** view.
   Caption: "Set each faction's relative size with one click. Live pie shows how the world divides;
   every faction is guaranteed at least one region. Kin factions split off automatically."

2. **`02-placement-advanced.png`** — Geographic Placement Settings, **Advanced** view (+ pie "By hostility").
   Caption: "Full per-faction tuning — resource weights, number of clusters, minimum cluster size,
   and a hostility pie so you can see the shape of the threat before you generate."

3. **`03-mod-settings.png`** — Options → Mod Settings → Regions and Societies.
   Caption: "Toggle any feature to play nice with other mods. Version-tagged partition algorithms,
   and a biome region-size weighter."

4. **`04-biome-region-sizes.png`** — the Biome region sizes editor.
   Caption: "Tune how large each biome's regions are — sparse biomes (ice, desert) default larger.
   Our values are the defaults; reset per-biome or all at once."

5. **`05-integration-card.png`** — the World Objects integration card (framework preview of the
   detected-mods table). Optional supporting shot.
